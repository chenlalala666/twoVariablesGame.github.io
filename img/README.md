# 二十四节气APP图片资源文件夹

此文件夹用于存放应用所需的图片资源，包括：

1. 节气相关图片：每个节气的代表性图片
2. 界面元素：图标、背景等
3. 用户头像示例

## 必要的图片文件

为了确保应用正常显示，请准备以下图片资源：

- `24jieqi_example.png` - 节气示例图片
- `avatar.png` - 用户头像示例
- 各个节气的图片，建议命名格式：`jieqi_立春.png`、`jieqi_雨水.png` 等
- 四季的背景图片：`spring_bg.png`、`summer_bg.png`、`autumn_bg.png`、`winter_bg.png`

## 图片规格建议

- 节气图片：建议尺寸 600x400 像素，JPG或PNG格式
- 用户头像：建议尺寸 200x200 像素，PNG格式（支持透明）
- 背景图片：建议尺寸 1080x1920 像素，JPG格式

请确保所有图片都具有适当的版权许可，可以使用免费的图片资源网站如Unsplash、Pexels等获取合适的图片。
