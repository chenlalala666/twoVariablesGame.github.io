# 二十四节气APP原型

这是一个展示中国传统二十四节气知识的移动应用原型。通过HTML、CSS和JavaScript构建，旨在提供一个直观的界面，帮助用户了解和探索二十四节气的文化内涵和养生知识。

## 项目结构

```
项目根目录/
├── css/               # 样式文件
│   └── styles.css     # 主样式文件
├── img/               # 图片资源
│   └── README.md      # 图片资源说明
├── js/                # JavaScript文件
│   └── main.js        # 主逻辑文件
├── screens/           # 应用界面
│   ├── home.html      # 首页
│   ├── jieqi_list.html    # 节气列表
│   ├── jieqi_detail.html  # 节气详情
│   ├── yangsheng.html     # 养生页面
│   └── profile.html       # 个人中心
└── index.html         # 入口文件（展示所有界面）
```

## 功能特点

- **节气信息展示**：详细介绍二十四节气的含义、时间和特点
- **节气养生知识**：根据不同节气提供相应的养生建议
- **季节变化**：根据季节动态变化界面颜色和主题
- **交互体验**：提供丰富的用户交互，如点击查看详情、搜索功能等

## 交互说明

本原型已实现的交互功能：

1. 底部标签栏导航 - 点击底部标签可切换不同页面
2. 列表项点击 - 点击节气列表中的项目可查看详情
3. 搜索支持 - 支持按回车键进行搜索
4. 节气标签筛选 - 点击季节标签可筛选相关内容
5. 卡片折叠/展开 - 点击节气卡片可展开或折叠详情
6. 返回按钮 - 可返回上一级页面

## 如何使用

1. 克隆或下载此项目到本地
2. 在浏览器中打开`index.html`文件（推荐使用Chrome或Firefox最新版本）
3. 通过界面上的各种控件和元素进行交互体验

## 设计说明

- 色彩：采用四季的代表色彩作为主题，春绿、夏红、秋黄、冬蓝
- 布局：遵循移动应用的常见布局，包括状态栏、内容区和导航栏
- 字体：使用无衬线字体，确保在移动设备上的清晰可读性
- 图标：使用Font Awesome图标库提供直观的视觉指引

## 兼容性

本原型设计主要面向移动设备，在以下环境测试最佳：
- 屏幕尺寸：375px × 812px（iPhone X尺寸）
- 浏览器：Chrome、Safari、Firefox最新版本
